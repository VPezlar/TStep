What Was Built
--------------
A complete SU2 CFD backend for TStep, selectable via flow_format = 'SU2'
in inputs.in. Zero changes to the mathematical core (Arnoldi.f90,
state_vector.f90, frechet_stencil.f90).

- src/SU2_IO.f90
    The core new module:

Key Design Decisions
--------------------
- Conservative<->primitive conversion exclusively in SU2_IO.f90; rest of
  TStep only sees primitive variables.
- Column indices discovered by name, never hard-coded; survives SU2 version
  drift.
- SU2 uses single static restart file; no time-stamped folders.
  find_endpoint_folder returns su2_solution_out directly;
  clear_endpoint_folder does rm -f on that file.
- Grid embedded in SU2 restart; baseflow_grid is unused for SU2.
- Writer preserves header verbatim; tokenizes old rows, replaces only the
  5 flow columns, reassembles.

Conversion Math
---------------
Conservative -> primitive:
    U = Momentum_x / Density
    V = Momentum_y / Density
    W = Momentum_z / Density
    p = (gamma_gas - 1) * (Energy - 0.5 * Density * (U^2 + V^2 + W^2))
    T = p / (Density * R_gas)
    rho = Density

Primitive -> conservative:
    Density    = rho
    Momentum_x = rho * U
    Momentum_y = rho * V
    Momentum_z = rho * W
    Energy     = p / (gamma_gas - 1) + 0.5 * rho * (U^2 + V^2 + W^2)

Review Bugs Fixed (commit 3285de6)
-----------------------------------
1. Sentinel gas constants: gamma_gas/R_gas init to -1.0; validate_paths
   rejects gamma <= 1 and R <= 0 with clear messages.
2. Row-count sanity check: after second-pass read, peek next line; error
   if it is another data row (catches silent truncation from blank lines).
3. Trailing-comma tokenizer: handles empty last field and adjacent commas
   without out-of-bounds.

Compilation
-----------
Clean compile verified with gfortran -O3 -Wall on macOS (arm64). Only
pre-existing warnings (set_blas_threads unused in main.f90, T unused in
write_SU2_restart — correct, not needed for the EOS write path).

Before First HPC Run
---------------------
1. Verify column names: head -1 a real SU2 restart file. Code expects:
   x, y, z, Density, Momentum_x, Momentum_y, Momentum_z, Energy.
   Some SU2 versions use different names (Conservative_1...Conservative_5,
   or X-Momentum). If different, update the 8 find_column string literals
   in SU2_IO.f90.

2. Smoke test: krylov_size=2 with the SU2 backend. The eps_s line alone
   validates the entire I/O border (parsing, column discovery, conversion,
   round-trip write).
